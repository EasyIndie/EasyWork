一条命令，
配置好开发环境

一份 config.toml 装好 Shell、Git、Vim、gh 与 AI 工具。 安装幂等、可回滚，macOS / Linux / Windows 通用。

macOS / Linux curl -sL https://raw.githubusercontent.com/EasyIndie/EasyWork/main/bootstrap.sh | bash
Windows irm https://raw.githubusercontent.com/EasyIndie/EasyWork/main/bootstrap.ps1 | iex

Go 静态单二进制，零运行时依赖 · 安装时校验 sha256 · 手动下载

三步开始

终端 
# 1. 轻量初始化：shell 别名 + git 别名，零交互
ew init
# 2. 按 config.toml 装好全套（--dry-run 可先预览）
ew install --yes
# 3. 查看状态与诊断
ew status
ew doctor

为什么用它

  • 单二进制，零依赖

    下载即用，卸载即删；不装 Node、Python 或任何运行时。

  • 声明式且幂等

    改 config.toml 再 apply；只在自己的 managed section 内改写，保留你原有内容并自动备份。

  • 人与机器都能读

    默认输出可读摘要；--json 给出字节级稳定的结果，日志一律走 stderr。

附带的设备防休眠

跑长任务时用 ew keepawake：只注册系统电源断言，不需要 sudo、不改系统电源策略； 默认「接电不睡、拔电照常节能」，status 报告真实断言状态。合盖仍会睡眠。

开启并设为开机自启 
ew keepawake on --persist
ew keepawake status
