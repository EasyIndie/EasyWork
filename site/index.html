EasyWork

开发环境配置工具。用一份 config.toml 安装并管理 Shell、Git、Vim、gh、 AI 工具，以及可选的设备防休眠。Go 静态单二进制，支持 macOS、Linux、Windows。

macOS / Linux
curl -sL https://raw.githubusercontent.com/EasyIndie/EasyWork/main/bootstrap.sh | bash
Windows · PowerShell
irm https://raw.githubusercontent.com/EasyIndie/EasyWork/main/bootstrap.ps1 | iex

安装时校验 sha256，装入 /usr/local/bin 或 ~/.local/bin； 固定版本用 EASYWORK_VERSION。其余版本见 Releases。

用法

终端 
ew init
ew install --yes
ew status

重复执行是安全的：已经正确的部分不会被重写。--dry-run 预览变更， --json 输出给脚本与自动化消费。

参考

命令作用
ew init轻量初始化：shell 与 git 别名，零交互
ew install按 config.toml 安装全部或指定组件
ew uninstall卸载并还原备份
ew status配置与模块状态
ew doctor依赖、网络、控制台编码、电源策略诊断
ew config读写 config.toml
ew keepawake设备防休眠：开启、关闭、状态
ew update自升级，下载后校验 sha256

完整命令见 ew help，模块清单见 ew list， 契约与 JSON 格式见 接口规格。

设备防休眠

长任务不被打断时使用 ew keepawake。它只注册系统电源断言 （macOS caffeinate、Linux systemd-inhibit、 Windows SetThreadExecutionState），不需要 sudo，也不修改系统电源策略。

开启并设为开机自启 
ew keepawake on --persist
ew keepawake status
mode
ac：接电生效、拔电按系统策略节能；always：电池也阻止睡眠
status
校验真实断言（macOS 读 pmset -g assertions），区分 active / pending-ac / stale / inactive
边界
合盖仍会睡眠；off 会同时拆除自启单元

说明

写入边界
只改写目标文件中的 managed section，其余内容原样保留；首次接管前备份，卸载时还原
输出
数据走 stdout、日志走 stderr；--json 信封固定为 {ok, command, data, error}，退出码取值封闭
兼容
config.toml、manifest 与 managed section 标记跨版本不变，升降级无需迁移
许可
